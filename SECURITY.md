# Security policy

## Supported versions

Security fixes are provided for the latest published minor release.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting for this repository. Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within seven days.

Sidekick stores prompts and agent output locally. Reports involving state-directory permissions, path traversal, command overrides, prompt transport, or process termination are especially useful. Never include real secrets or private agent transcripts in a report.
