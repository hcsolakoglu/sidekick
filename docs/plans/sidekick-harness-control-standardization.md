### Control data schema

`RunMeta.controls` canonical source of truth olur. Her kontrol, gönderilen değer ile provider/runtime tarafından gerçekten etkinleştiği kanıtlanan değeri birbirine karıştırmayan aynı gözlem şemasını kullanır:

```ts
type ObservationStatus = "requested" | "applied" | "clamped" | "unknown" | "unsupported";
type ObservationSource =
  | "user"
  | "legacy"
  | "adapter"
  | "native-argv"
  | "native-config"
  | "native-environment"
  | "provider-reported"
  | "runtime-output"
  | "unknown";

interface ControlObservation<T> {
  requested: T | null;
  applied: {
    mechanism:
      "cli-flag" | "config-override" | "model-variant" | "inherit-native" | "omitted" | "none";
    value: T | string | null;
    source: ObservationSource;
    key?: string;
    configPath?: string;
    observedValueRedacted?: string;
    reason?: string;
    argv?: string[];
  } | null;
  effective: {
    value: T | string | null;
    source: "provider-reported" | "runtime-output" | "unknown";
    fieldPath?: string;
    artifactPath?: string;
    observedValueRedacted?: string;
    reason?: string;
  } | null;
  status: ObservationStatus;
}

interface HarnessControls {
  model: ControlObservation<string>;
  provider: ControlObservation<string>;
  transport: ControlObservation<
    "cli-subprocess" | "chat-completions" | "responses" | "stdin" | "unknown"
  >;
  effort: ControlObservation<string>;
  permission: ControlObservation<string>;
  sandbox: ControlObservation<string | boolean>;
  workspaceTrust: ControlObservation<boolean>;
  agentProfile: ControlObservation<string>;
  budget: ControlObservation<string>;
  cwdRestore: ControlObservation<boolean>;
}
```

`requested` kullanıcı veya legacy metadata’dan gelir. `applied`, adapter’ın gerçekten argv/config/model-variant olarak uyguladığı mekanizmadır. `effective` yalnızca provider/runtime kanıtı varsa doldurulur; bilinmiyorsa `null` ve `status: "unknown"` kalır. Adapter’ın gönderdiği flag tek başına effective değer kanıtı değildir. `unverified` yalnızca capability support/report union’ına aittir; `ObservationStatus` içinde bulunmaz. Native default mirası için `status: "applied"`, `applied.mechanism: "inherit-native"` ve `source: "native-environment"` veya `"native-config"` kullanılır; belirli native value effective olarak iddia edilmez. Generic precedence ancak G1’de key table dondurulduktan sonra uygulanır: her engine için exact CLI flag, environment variable, native config key ve adapter default ayrı kaydedilir. G1 key table yoksa ilgili source `unknown` olur; “environment/native config” varsayılan bir catch-all değildir. Aynı eksende conflict varsa explicit Sidekick request `requested`, native invocation’da gerçekten kullanılan değer `applied`, provider/runtime bildirimi `effective` olarak ayrılır; sessiz merge veya overwrite yoktur.

G1 key table başlangıç adaylarını kaynakla birlikte şu şekilde tutar; bunlar tüm engine’lara genellenmez:

| Engine | Explicit CLI/native key                                                                                             | Documented environment/config key                                                                        | Scope and rule                                                                                                                                 |
| ------ | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| Devin  | `--model`, `--permission-mode`, `--sandbox`, `--respect-workspace-trust`                                            | `DEVIN_MODEL`, `DEVIN_PERMISSION_MODE`, `DEVIN_SANDBOX`; config/profile ayrıca kaynakla doğrulanır       | Explicit Sidekick request ile native environment conflict’i `requested/applied/effective` olarak ayrılır; sandbox/permission coupling korunur. |
| Codex  | initial `--sandbox`; resume/config `-c sandbox_mode=...`, `-c approval_policy=...`, `-c model_reasoning_effort=...` | Generic environment key varsayılmaz; config reference ve executable probe source olarak kaydedilir       | Resume placement ve selected model support ayrı kanıtlanır.                                                                                    |
| Hermes | Sidekick mevcut adapter’da yalnızca `--model`; effort/permission flag’i varsayılmaz                                 | Hermes config `agent.model`, `agent.reasoning_effort` ancak adapter/CLI integration probe ile doğrulanır | Config global ise run metadata’ya source olarak yazılır; Sidekick bunu native per-run control diye ilan etmez.                                 |

Bu tabloya girmeyen environment/config adı implementation’da kullanılmaz. Conflict fixture’ı en az explicit CLI vs native environment ve native config vs adapter default durumlarını test eder.

### Normative precedence

`requested/applied/effective` gözlemleri precedence yerine geçmez. Her command için deterministik kaynak sırası şöyledir:

| Context                 | Winner order                                                                                                                                                                                                                               | Rule                                                                                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| New `spawn`             | explicit Sidekick control → validated legacy `mode`/metadata (yalnız explicit control yoksa) → documented native environment → documented native config/profile → adapter/canonical default                                                | Explicit `--model`, `--permission`, `--sandbox`, `--workspace-trust` ve `--effort` native argv/config’e açıkça taşınır. Native env/config açık request’i override edemez.                                                                                                                                                                                                               |
| `adopt`                 | explicit adopt controls → validated legacy inputs → documented native environment → documented native config/profile → adapter/canonical default                                                                                           | Adopt’ta henüz persisted `RunMeta.controls` yoktur. Resolved controls adopted-session validation başarılı olduktan sonra, run creation’dan önce persist edilir.                                                                                                                                                                                                                         |
| `resume`                | persisted immutable `RunMeta.controls` → yalnız command’ın açıkça izin verdiği explicit override → yalnız persisted axis `inherit-native` ise documented native environment → documented native config/profile → adapter/canonical default | Persisted explicit controls current process environment/config’den üstündür. Persisted `inherit-native` kararı drift’in izin verilen tek istisnasıdır ve `applied.mechanism` ile görünür.                                                                                                                                                                                               |
| `send`                  | persisted immutable `RunMeta.controls` → hiçbir command override’ı yok                                                                                                                                                                     | `send` bütün control flag’lerini reddeder: `--effort`, `--model`, `--permission`, `--sandbox`, `--workspace-trust`, provider/transport ve profile dahil. Persisted `inherit-native` yalnız daha önce seçilmiş source key ile gözlemlenir; current request ile değişmez.                                                                                                                 |
| `fallback`              | persisted immutable `RunMeta.controls` and persisted native provenance → yalnız persisted axis `inherit-native` ise aynı documented native source key → adapter/canonical default                                                          | Fallback hiçbir control axis’ini, engine’i, provider’ı, modeli veya transport’ı değiştirmez; resume ile aynı controls kullanır. Farklı route/engine/profile gerekiyorsa bu ayrı explicit yeni run’dır. Persisted `inherit-native` source key/value yeniden üretilemiyorsa fallback exit 2 veya `effective=unknown` policy fixture’ında açıkça seçilir; implicit re-resolution yasaktır. |
| Native defaults         | documented env → documented native config/profile → adapter default                                                                                                                                                                        | Bu sıra yalnız ilgili engine için G1 key table’da exact olarak doğrulanmışsa kullanılır. Doğrulanmamış native default implementation’a alınmaz.                                                                                                                                                                                                                                         |
| Provider/runtime report | hiçbir requested/applied değerinin yerine geçmez                                                                                                                                                                                           | Yalnız `effective` observation’ı doldurur; rapor yoksa `effective.value=null`, `status=unknown` kalır.                                                                                                                                                                                                                                                                                  |

`effort=auto` veya explicit control verilmemiş bir axis native default mirası anlamına geliyorsa `applied.mechanism="inherit-native"` ve source key kaydedilir; bu, belirli bir native value uygulanmış gibi raporlanmaz. G1 exact key/precedence kanıtı yoksa model-dependent explicit request `unverified` capability olarak kalır ve preflight’ta exit 2 olur. Bu kurallar Codex `-c`, Devin `DEVIN_*`/CLI ve Hermes config kaynakları için ayrı fixtures ile assertion’a bağlanır.

Capability registry anahtarı şu tuple’dır:

```text
(engine, provider, model, transport, toolVersion, axis, action)
```

`action` yalnızca `initial | adopt | resume | fallback` olabilir. `toolVersion` executable-backed engine’larda capability key’in zorunlu boyutudur; runtime version evidence entry ile uyuşmuyorsa tuple `unverified` sayılır ve explicit request exit 2 verir. `requested`, `applied` ve `effective` gözlemleri bu tuple’a göre raporlanır. Initial ve adopt metadata’sı run creation’dan önce resolve edilir; initial/adopt controls resume/fallback sırasında immutable olarak taşınır.

`ObservationStatus="clamped"` yalnız provider/runtime açıkça requested değerden farklı applied/effective değer bildirdiğinde kullanılabilir; `reason` ve provenance yazılır. Adapter’ın kendi sessiz downgrade’ı clamped sayılmaz ve yasaktır. İlk release’te kullanıcıya `allowClamp` override’ı açılmaz; explicit request’in runtime’da clamp edildiği kanıtlanırsa run/turn `control-clamped` ile exit 2 olur. Clamped observation diagnostic metadata’da korunabilir, fakat hiçbir durumda silent success veya warning-only success değildir.

### Required cross-product oracle

Capability validation eksenleri bağımsız string listeleri olarak çarpmaz; registry tuple’ına bağlı constraint oracle kullanır. İlk zorunlu Devin oracle’ı:

| Requested controls                       | Expected preflight result                                                                                                             | Native application                                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `sandbox=false`, `permission=normal      | accept-edits                                                                                                                          | dangerous`                                                                                           | Supported if model/provider/transport record exists                                          | `--sandbox` omitted; current Devin transport maps canonical `normal` to native `--permission-mode auto`, while other accepted values remain native; record requested vs applied separately |
| `sandbox=false`, `permission=auto`       | Supported only as native/legacy alias                                                                                                 | Canonicalize requested `auto` to canonical `normal`; current transport records applied native `auto` |
| `sandbox=true`, `permission=autonomous`  | Current parser/help probe and official docs accept this coupled combination; support remains versioned by exact Devin binary evidence | `--sandbox --permission-mode autonomous`                                                             |
| `sandbox=true`, `permission=normal       | accept-edits                                                                                                                          | dangerous`                                                                                           | Unsupported, exit 2 before discovery/store because autonomous is the sandbox permission mode | Never emit partial argv                                                                                                                                                                    |
| `sandbox=false`, `permission=smart`      | Current `devin 3000.3.27` parser rejects `smart` despite condensed help text; unsupported/unverified, exit 2                          | Never emit `--permission-mode smart` until a version-specific G1 probe promotes it                   |
| `sandbox=false`, `permission=autonomous` | Unsupported, exit 2 because autonomous requires sandbox                                                                               | Never emit partial argv                                                                              |

Other engine cross-products are generated from the same table format in G1. Every row has an expected preflight `exit 0` or `exit 2` oracle. `unverified` is a capability/report status and a reason for deterministic `exit 2`; it is never an exit code or a successful preflight result. A generic Cartesian-product loop is not sufficient.

### Effort sözlüğü

İlk release’te global enum, bütün engine/model kombinasyonlarının native olarak desteklediği değerler listesi olmayacaktır. Global katman yalnızca bilinen label’ları temsil eder; geçerlilik capability registry’de engine + provider + model + transport seviyesinde çözülür.

- Parser vocabulary ile native support listesi ayrıdır. Bilinen candidate label’lar `auto`, `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max` olabilir; bunların hiçbiri G1 capability kaydı olmadan selected model için supported request value sayılmaz.
- `max` Claude-specific değildir. Codex’in güncel model sayfası Max/Ultra ürün seçeneklerini gösterir; API reasoning dokümanı da effort değerlerinin model-dependent olabileceğini belirtir. Buna karşılık Codex config reference `model_reasoning_effort` için `minimal | low | medium | high | xhigh` listeler. Bu nedenle Max’in hangi native key/transport/model kombinasyonunda uygulanabildiği G1 ile kanıtlanmadan global native support ilan edilmez.
- `none` bazı model kataloglarında “no thinking” varyantıdır; bu değer de otomatik olarak bütün Codex modellerine veya bütün engine’lara açılmaz.
- `ultra` ürün seviyesi subagent/workflow modu olabilir. Native `model_reasoning_effort` key’i olduğu kanıtlanana kadar effort label’ı değil, profile/workflow adayıdır.
- `ultracode`, effort olarak değil profile/workflow adayı olarak ele alınır.
- `xhigh` dahil hiçbir non-`auto` label, model-dependent olduğu bilinen bir engine’da model kaydı olmadan koşulsuz kabul edilmez.
- Seçili model bilinmiyor ve istenen değer model-dependent ise preflight fail-closed davranır. `auto` native override geçirmeden harness/session default’unu kullanır.
- Devin’de ayrı native `--effort` flag’i yoksa `--model glm-5-2-max` gibi explicit model variant’ları effort isteğine sessizce dönüştürülmez; uygulanan mekanizma `model variant`, effective effort ise provider-reported veya unknown olarak raporlanır.
- Mock, registry’de açıkça tanımlanan seviyeleri ve model-dependent kararlarını deterministic test için simüle eder; belirsiz bir “full vocabulary” tanımı kullanılmaz.

`auto` hiçbir native override geçirmemek ve harness/session default’unu kullanmak demektir. Silent downgrade, retry ve model adına bakarak implicit effort çıkarımı yoktur; explicit model variant’ı ise ayrı `applied mechanism` olarak görünür.

### Legacy `--mode` migration

- `--mode` bir release boyunca deprecated legacy input olarak kalabilir.
- Canonical adapter input `controls` object’idir.
- `RunMeta.mode` schema-version-1 uyumluluğu için korunur; yeni `controls` alanı canonical source of truth olur.
- `resolveControls(meta)` önce yeni controls alanını, yoksa engine-specific legacy `mode` mapping’ini kullanır.
- Legacy mapping:
  - Codex: yalnızca `read-only|workspace-write|danger-full-access` canonical sandbox değerlerine map edilir; diğer legacy `mode` değerleri raw argv’ye geçirilmez, `legacy-unmappable` olarak açıkça raporlanır.
  - Devin: canonical permission değerleri `normal|accept-edits|smart|dangerous|autonomous` olarak doğrulanır; `auto` yalnızca `normal` legacy alias’ıdır. `sandbox=true` yalnızca `permission=autonomous` ile map edilir; diğer sandbox/permission cross-product’leri unsupported/legacy-unmappable olur.
  - Claude: resmi permission vocabulary doğrulanarak `mode` legacy value → permission mapping’i yapılır.
  - Hermes: mode şu an etkisizdir; yeni sözleşmede silent no-op olmaması için explicit unsupported/warning kararı G1/T5’te verilir.
- `--mode high` için hata metni `--effort high` önerir, fakat Devin’e `--permission-mode high` gönderilmez.
- Yeni public örneklerde `--mode` kullanılmaz.

## Non-obvious prerequisites

- Registry oluşturulmadan `EngineContext` içine eksen eksen dağınık optional string eklenmemeli. Önce tek `HarnessControls`, `ControlObservation` ve `resolveControls` kontratı dondurulmalı.

- `isRunMeta` yalnızca eksik alanı default’a çevirmemeli, bozuk effort/controls değerini `corrupt-meta` olarak reddetmeli.
- `command.json` zaten tam invocation argv’sini kaydediyor. Yeni eksenlerde yeni audit formatı icat etmek yerine initial/resume command kayıtları üzerinde test kurulmalı.
- `spawn` validation sırası `getEngine` ve platform kontrolünden hemen sonra gelmeli. `RunStore.initialize()`, `promptFrom`, `directory`, lock, `store.create` ve worker start bundan sonra çalışmalı.
- `adopt` validation sırası `getEngine` ve platform kontrolünden hemen sonra gelmeli. `RunStore.initialize()`, `directory` ve özellikle Devin/Hermes `validateAdoptedSession` discovery’sinden önce controls/name/session syntax preflight tamamlanmalı. Geçerli preflight sonrasında yalnız discovery-lock root oluşturulabilir; `runs/` ve normal run lock’ları adopted-session validation sonrasına kalmalı.

- `capabilities` unknown engine kontrolünü tüm selected names için stdout yazmadan önce tamamlamalı. Karışık known+unknown çağrıda kısmi JSON basılmamalı.
- Aynı `lifecycle.test.js`, `cli.ts`, `spawn.ts` ve `adopt.ts` üzerinde çoklu agent değişikliği güvenli paralellik değildir. Ayrı worktree bile merge çakışmasını ortadan kaldırmaz; ortak dosyalar seri entegre edilmelidir.

## Dependency and parallelism summary

- **Dependency-constraining path:** `T1 -> T2 -> T3 -> T4 -> T5 -> T6 -> T7 -> T8/T9 -> T10 -> T11 -> T12`.
- **Critical path:** Schedule estimates ve capacity verilmediği için gerçek critical path iddia edilmiyor. Yukarıdaki yol dependency-constraining path’tir.
- **Safe parallel window:** T5 ve T6 parallel değildir; T5 canonical adapter extension point’lerini dondurduktan sonra T6 başlar. T8 ve T9 ayrı worktree’lerde yürüyebilir, fakat `cli.ts`, public surface ve integration test merge’leri seri olmalıdır.
- **Unsafe parallelism:** Aynı canonical registry üzerinde T5/T6 editleri; aynı `--dir` ile Devin veya Hermes worker/discovery/adopt validation çalıştırmak; aynı `lifecycle.test.js`, `cli.ts`, `spawn.ts` veya `adopt.ts` üzerinde shared-tree edit yapmak.
- **Integration points:** T7 adapter/lifecycle convergence, T10 CLI surface freeze, T12 package verification.
- **Delegation protocol:** Her Devin worker’a exact file scope, no publish/commit/push sınırı ve tek bir verification command verilir. `sidekick wait` ile beklenir, `sidekick result --json` alınır, terminal status ve `exitCode` bağımsız doğrulanır. Failed worker sonucu başarı olarak kabul edilmez.
