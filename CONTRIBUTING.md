# Contributing

Thank you for improving sidekick.

Read [AGENTS.md](AGENTS.md) first. It is the single canonical list of repository, portability, testing, documentation, and security rules for both humans and AI agents. Do not duplicate that rule list here.

1. Use Node.js 20 or newer (`nvm use` selects the recommended version).
2. Install exactly the locked dependencies with `npm ci`.
3. Create a focused branch.
4. Follow the verification contract in `AGENTS.md`.
5. Open a pull request that explains the behavior, tests, and any user-facing changes.

Open an issue before a large architecture change. By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
