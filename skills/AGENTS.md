# Sidekick

Use `sidekick doctor ENGINE`, then delegate with `sidekick spawn ENGINE NAME --dir PATH -- "PROMPT"`. Start one background `sidekick wait NAME... --all --json` for a batch, continue independent work, and harvest with `sidekick result NAME --json`. Check `sidekick status --json` and `exitCode`. Continue with `sidekick send NAME -- "FOLLOW-UP"`; use `sidekick adopt` for an existing session, `sidekick tail` for live output, `sidekick cancel` for a resumable full-tree stop, and `sidekick clean` for terminal-run retention. Install harness guidance with `sidekick skill install HARNESS`. Keep task scopes independent and include constraints plus verification in every prompt.
