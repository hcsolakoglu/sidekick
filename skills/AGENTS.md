# Sidekick

Use `sidekick doctor ENGINE`, then delegate with `sidekick spawn ENGINE NAME --dir PATH -- "PROMPT"`. Start one background `sidekick wait NAME... --all --json` for a batch, continue independent work, and harvest with `sidekick result NAME --json`. Check `status` and `exitCode`. Continue with `sidekick send NAME -- "FOLLOW-UP"`; use `adopt` for an existing session, `tail` for live output, and `cancel` for a resumable full-tree stop. Keep task scopes independent and include constraints plus verification in every prompt.
